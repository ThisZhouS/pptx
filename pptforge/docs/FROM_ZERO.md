# 从零生成能对标的 PPT：方法论与达标表

目标：不看模板、不抄版式，仅凭规则从零生成一份，指标落在 91 个模板的中位区间内。
产物：`samples/template-grade.pptx`（15 页，脚本 `scripts/build_template_grade.py`）。

### 字号

唯一字号 11 档，最大字 = 正文 **5 倍**。封面 54–72、页标题 28–40、正文 14–18、页脚 10。

### 配色

91/91 模板是**浅底 + 黑字**（对比 21:1）；accent 饱和 0.65、明度 0.77、**与背景对比 4.7**（WCAG AA）；色相蓝占 69%。

### 栅格

**不用 12 列栅格**（吻合度只有 17%）。0.25in / 0.5in / 1.0in 网格各约 33%，说明是按英寸手工对齐。

## 四、实现路径（全部在引擎里，不靠模板）

| 规则 | 代码落点 |
| --- | --- |
| 上紧下松边距 | `design.MARGIN = 0.62`，header 上移到 0.46/0.78，kicker 0.34 |
| 字号层级 5:1 | 标题 40 / 正文 18 / 页脚 10 / 章节编号 108 |
| 装饰 7 个 | `design._decor`：3 点 + 3 色块 + 细线 + 页码 |
| 左侧图 38% | `design.bullets` 的 `image` 分支 |
| 两列 | `design.bullets` 的 `columns: 2`（按要点成对切分） |
| accent 对比 ≥4.5 | `build_template_grade.accent_from_hue` 迭代明度 |
| 浅底黑字 | `Theme.preset("light")` |
| 1 click + delay 瀑布 | `deck._anim_items` 的 stagger 累积；每页动画表 |
| 装饰也动画 | `DECOR_ANIMS`（点 fade、块 wipe、线 wipe、页码 fade） |

## 五、边界（还做不到的）

1. **形状 13 vs 15.5**：差的 2 个是"序号块"与"图标位"，需要额外图形元素。
2. **有图页 0% → 16%**：`template-grade` 没有配图；图片素材是外部依赖，不是算法问题。
3. **自由曲线**：模板里的大量 freeform（国潮/工科类）引擎不支持，只支持预设几何。
4. **60+ 自定义版式**：模板为每种页面单做版式，我只有 9 种内置 layout。
5. **识图只测首页**：风格标签代表封面气质，不等于内页版式。
