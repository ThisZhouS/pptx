## 五、识图功能（`mcp_ppt/vision.py`）

渲染首页后算 8 个量化特征，再归到 6 个风格标签：

| 特征 | 用途 |
| --- | --- |
| `dominant`（前 5 主色及占比） | 判断基调是深色还是浅色、有没有主色块 |
| `ink_ratio` | 信息密度（0.1 = 极简，0.9 = 满版） |
| `edge_density` | 元素/细节多少 |
| `saturation` / `brightness` / `contrast` | 莫兰迪低饱和、马卡龙高饱和、深色主题 |
| `regions`（上/下/左/右主色） | 判断页眉页码、底部色块等结构 |
| `colorfulness` | 颜色多样性 |

91 个样本的标签分布：**低饱和（莫兰迪/灰调）最多**，其次浅色留白、信息密集、图片/色块主导、深色极简。
这与"中文模板偏克制配色"的直觉一致。

用法：

```python
from mcp_ppt.vision import deck_vision
deck_vision("x.pptx", pages=1, width=800)
# → {"features": [{"style": "低饱和（莫兰迪/灰调）", "ink_ratio": .42, "brightness": .78, ...}]}
```

## 六、对引擎的修正（已落地 / 待落地）

**已落地**

| 项 | 依据 |
| --- | --- |
| 默认时长 `DUR = 0.5` | 500ms 占 54238 次 |
| 预设分工：标题 `wipe`、正文 `fade`、卡片 `faded-zoom` | fly/wipe/fade 前三，faded-zoom 用于图片卡片 |
| morph 只用于图片轮播，不做章节转场 | 469 页 morph 全集中在"动态"板块的图片轮播 |

**待落地（按性价比排序）**

1. ~~默认不加动画~~ → 按需求改为**默认走高动画配方**（见第八节）：每页全元素动画 + 1 个 click + delay 瀑布。
2. **提高形状密度**：给 `bullets`/`metrics` 版式补"装饰层"（细线、序号块、分隔块），从 5 个形状提到 15–20 个。
3. **freeform 支持**：模板里大量自由曲线（`Freeform: Shape 35` 之类），是国潮/工科类视觉的核心。
4. **图片推镜序列**：`morph` + 每页不同 `srcRect` 的自动生成器。

## 七、局限

- 识图只渲染了首页，代表"封面风格"，不等于内页版式风格。
- `analyze` 只读前 40 页的动画（`max_slides=40`），超过 40 页的大文件统计会偏低（如 128 页的逻辑架构板块显示 0 动画，实际可能有）。
- 风格标签是启发式规则，不是分类模型；`均衡型` 占比高说明阈值还需校准。

### 四条可复用的规则

1. **几乎不用 click 分组**：click 组平均 **0–1.7 个**，其余全是 `withEffect`（同一条时间轴自动连播）。
   观众不需要点 20 次才能看完一页。
2. **靠 delay 拉瀑布**：最大 delay 从 0 到 **7000ms**（黑白灰动态 03 是 3000ms、高级极简 43 是 7000ms）。
   一页的动画可以持续 3–7 秒，节奏完全由 delay 控制，而不是靠 "after previous" 串行。
3. **一页混用 4–6 种预设**：fade / wipe / fly / ascend / faded-zoom / peek / custom-path 交替，
   而不是全篇一种效果。欧美简约 5 号甚至 202 次全用**自定义路径**。
4. **动画条数 ≈ 形状数**：34.4 条/页对应 20–30 个形状，即"每个元素都动"。

### 已落到引擎

`motion.py` 的 `subtle` 套餐按这套配方重写（此前是"每页 3–5 条、1 个 click、全部 stagger 0.1"的保守版）：

| 页型 | 编排 |
| --- | --- |
| 封面 | 装饰条 wipe → 标题 **fly** → 副标题 **ascend** → meta fade → 细线 wipe（1 click + 4 with，delay 递增到 0.25） |
| 内容 | kicker fade → 标题 **fly** → 细线 **wipe** → 正文 **ascend** + `build: paragraph`（逐段浮出）→ 页脚 fade |
| 指标 | kicker → 标题 → 细线 → 卡片 **faded-zoom** → 卡内数值 fade → 卡内标签 fade（**16–20 条/页**） |

`codecraft-v3.pptx` 重建后：**162 个动画 / 19 页**（原先 118），
预设混用 fade 58 + wipe 42 + ascend 39 + faded-zoom 13 + fly 10，
触发 withEffect 143 / click 19 —— 与模板配方同一数量级。

### 仍差的

模板每页 20–30 个形状，我的版式只有 5–20 个，所以动画条数上限低（内容页 8 条 vs 模板 16 条）。
要追平，得先补形状密度（装饰层），再谈动画条数。
