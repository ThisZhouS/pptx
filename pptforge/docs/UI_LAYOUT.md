# UI 与布局设计：444 个内容页的实测规律

方法：91 个模板各取第 2–6 页（跳过封面），共 **444 个内容页**，
把每个形状的坐标归一化到页面比例后统计区域、列栅格、图文关系、装饰与留白。
脚本 `scripts/analyze_ui_layout.py`，数据 `samples/ui_layout.json`。

## 一、页面分带：85% 的内容压在上 2/3

| 区域带（页面高度） | 形状数 |
| --- | --- |
| top（0–20%） | 2893 |
| **upper（20–45%）** | **2990** |
| middle（45–70%） | 2527 |
| lower（70–90%） | 1106 |
| bottom（90–100%） | **162** |

内容集中在上三分之二，底部 10% 几乎是空的（只放页脚与页码）。
这解释了"上紧下松"的边距——**留白不是平均分配的，而是全部堆在底部**。

## 二、列栅格：多列占一半以上

| 1 列 | 2 列 | 3 列 | 4 列 | 5 列以上 |
| --- | --- | --- | --- | --- |
| 128（29%） | 86（19%） | 66（15%） | 67（15%） | 97（22%） |

单列只占 29%，**2–4 列合计 49%**。模板不是"一段文字走到底"，而是把内容切成并列块。

## 三、图文关系：54% 的页有图，左侧图最常用

| 无图 | **左侧** | 右侧 | 居中 | 上方 | 全屏 |
| --- | --- | --- | --- | --- | --- |
| 202（45%） | **118（27%）** | 56（13%） | 42（9%） | 19（4%） | 7（2%） |

图片面积占比中位只有 **0.02** —— 说明大多数"图"是**小图标与装饰图**，
不是大配图。大图（全屏）只占 2%。

## 四、装饰元素：每页 7 个，占形状总数近一半

| 装饰类型 | 总数（444 页） | 每页均值 |
| --- | --- | --- |
| 小色块 chips | 3011 | **6.8** |
| 圆点/图标位 dots | 2495 | **5.6** |
| 细长条 bars | 238 | 0.5 |

**每页前景形状中位 15.0 个，其中 7 个是装饰。** 装饰以"小色块 + 圆点"为主，
细线反而用得很省。

## 五、垂直留白节奏：0.58 英寸

相邻元素之间的空白中位 **0.077（≈0.58in）**。这是"块与块之间的呼吸"，
比段内行距大得多——层级靠这个间距拉开，而不是靠字号。

## 六、落地：形状密度从 5 提到 10

改 `design.py`，给内容页加**装饰层**（`_decor`）：

| 元素 | 规格 |
| --- | --- |
| 右上角三个点 | 0.085in 圆点，主色 / 辅色 / 弱色各一 |
| 底部分隔线 | `CONTENT_W - 0.9in` 宽，0.75pt，弱色 |
| 页码 | 右下角 10pt |
| 章节页码 | 右下角 10pt（章节页不加点，避免抢戏） |

实测：**每页前景形状从 5 提到 10（中位），装饰中位 7** —— 与模板的 7.0 完全一致。
`layout_check` 仍 0 溢出，`validate` 0 problem，动画数 162 不变。

## 七、还差的

| 项 | 模板 | 现在 |
| --- | --- | --- |
| 前景形状/页 | 15.0 | **10** |
| 有图页占比 | 54% | **0%**（只有 `image` 版式放图） |
| 2–4 列布局 | 49% | 单列为主（`metrics` 是多列但只在卡片页） |
| 装饰构成 | chips 6.8 + dots 5.6 + bars 0.5 | 3 点 + 1 线 + 页码 |

补齐路径（按性价比）：

1. **给 `bullets` 加可选图片位**（左侧 40% 图 / 右侧 60% 文），一步补上"有图页 54%"与"左侧图 27%"两条规律。
2. **`bullets` 支持 2 列**（`columns: 2`），对应 49% 的多列页。
3. **装饰层加 3 个色块**（chips），把形状密度推到 13–15。

这三项都在 `design.py` 内部，不动内容与动效，且都可以用现有的 `layout_check` + 形状密度指标验证。

## 八、第二轮落地：图片位、两列、装饰色块

三项都是 `design.py` 内的改动，不动内容与动效。

### 1. `bullets` 支持左侧图片位（左 38% 图 / 右 62% 文）

对应模板里"左侧图 27%"这条规律。传 `"image": "path.png"` 即生效，
图与正文自动分栏，正文宽度按比例收缩，提示文字不挤压。

### 2. `bullets` 支持两列（`"columns": 2`）

按"要点 + 说明"**成对切分**（不会把一对拆到两列），左右各 50%，中间 0.5in 间距。
对应模板里 2–4 列占 49% 的规律。

### 3. 装饰层补 3 个色块（chips）

在原来 3 点 + 细线 + 页码的基础上，再加 3 个 0.17×0.045in 的小色块 ——
模板里 chips 是最主要的装饰（6.8/页），之前只有点没有块。

### 4. 装饰也参与动画

`decor-dot1..3` / `decor-chip1..3` / `footer-rule` / `page-num` 各自挂 fade / wipe 动画，
对应模板"每个形状都动"的特征。

### 落地后的实测（19 页）

| 指标 | 模板中位 | 第一轮 | **第二轮** |
| --- | --- | --- | --- |
| 前景形状/页 | 15.0 | 10 | **13** |
| 装饰/页 | 7.0 | 7 | **10** |
| 动画/页 | 15–34 | 8 | **16–28**（总 269） |
| 预设种类 | 4–6 | 3 | **5**（fade 110 / wipe 94 / ascend 39 / faded-zoom 16 / fly 10） |
| 有图页 | 54% | 0% | **16%**（3 页左侧图） |
| 2 列以上 | 49% | 0 | **58%**（含 metrics 的四列） |
| `layout_check` | — | 0 | **0** |

动画总量从 162 提到 **269**，每页 16–28 条，落在模板 15–34 的区间内。

### 仍差的

- **有图页 16% vs 54%**：图片素材是瓶颈。当前只用 3 张程序生成的抽象图（AST 渐变网格 / GNN 同心环 / LLM 节点图），
  真实项目应基于内容配图。
- **装饰 10 vs 7**：略多，可减 3 个 chips 回到 7。
- **形状 13 vs 15**：还差 2 个，可通过给正文加序号块（`01` `02` 前缀小方块）补齐。
