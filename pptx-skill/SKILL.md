# pptx-skill

从 `Resource/` 里 **2120 个真实模板（全量，不再抽样）** 拆出来的素材库 + 生成引擎。给定大纲和风格，产出**指标落在模板中位区间**的 .pptx。

## 为什么不用「套模板」的思路

模板的骨架是 60+ 个自定义版式和几十个 freeform 装饰，直接套会把内容挤变形；而它们的**可迁移部分是好测量的**：
边距、字号层级、覆盖率、装饰密度、动效节奏。本项目把这些量化成参数，再用引擎重建版式 —— 于是任何大纲都能得到同一套设计语言。

## 快速开始

```bash
cd pptx-skill
python scripts/build.py --demo --out demo.pptx --style 科技
python scripts/build.py my-outline.json --out deck.pptx --task 汇报
python scripts/build.py my-outline.json --out deck.pptx --style 极简
```

依赖：Python 3.10+、`python-pptx>=1.0.2`、`lxml`。引擎已内置（`engine/`），无需另装本项目。

## 大纲格式

```json
{
  "title": "演示标题", "subtitle": "副标题", "author": "汇报人", "date": "2026",
  "footer": "页脚文字",
  "sections": [
    { "heading": "章节名", "kicker": "01 · 标签", "title": "本页标题",
      "type": "bullets",
      "points": [{ "title": "要点", "detail": "说明（作为二级）" }] },

    { "heading": "数据", "title": "关键指标",
      "cards": [{ "value": "12%", "label": "留存提升" }] },      

    { "heading": "对比", "title": "参数表",
      "rows": [["指标", "现在"], ["耗时", "3s"]] },

    { "heading": "观点", "title": "一句话",
      "quote": "设计感来自约束。", "source": "出处" }
  ]
}
```

`type` 可省略：有 `cards` → 指标卡页，有 `rows` → 表格页，有 `quote` → 引用页，否则要点页。
每个 section 会生成「章节页 + 内容页」两页。

## 风格

| 风格 | 适合 | accent（色相/饱和/明度） | 动效 |
| --- | --- | --- | --- |
| 极简 | 答辩、评审 | 205/0.72/0.80 | 无动画 |
| 商务 | 汇报、方案、投标 | 212/0.68/0.62 | 8 条/页 |
| 科技 | 产品、技术分享、路演 | 195/0.78/0.85 | 18 条/页，带装饰动画 |
| 国潮 | 文化、非遗、品牌 | 8/0.62/0.55 | 6 条/页 |
| 文艺 | 画册、作品集 | 32/0.35/0.62 | 4 条/页 |
| 沉稳深色 | 发布会、夜场 | 210/0.55/0.72 | 12 条/页 |

`--task` 会自动映射：汇报→商务、答辩→极简、路演→科技、培训→商务、作品集→文艺、文化→国潮、发布会→沉稳深色。
accent 会按**对比度下限 4.5** 自动压明度（模板实测中位 4.72，WCAG AA）。

## 素材库（`assets/`）

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `styles.json` | 6 种风格 × 配色/动效/版式偏好 + 任务映射 | 62 板块 × 2120 文件 |
| `palettes.json` | 5 个色相族的 accent 参数与样本色 | 91 个主题的 clrScheme |
| `layouts.json` | 边距、覆盖率、对齐线、形状密度分布（P10/50/90）、列数、图文关系、字号层级、栅格 | 444 内容页 + 15407 形状 + 2120 文件 |
| `motion.json` | 时长分布、预设配比、click/with 规则、delay 瀑布、动画分档、14 个模板的实测配方 | **2120 个模板** |
| `decor.json` | 装饰元素规格（chip/dot/rule/page-num）+ 62 板块画像 | 444 个内容页 + 2120 文件 |

## 动画分档（全量 2120 个模板实测）

| 档位 | 动画/页 | 文件数 | 占比 | 对应 recipe |
| --- | --- | --- | --- | --- |
| zero | 0 | 792 | **37%** | `none` |
| low | 0–3 | 367 | 17% | `subtle` |
| mid | 3–8 | 618 | 29% | `rich` |
| high | 8–15 | 285 | 13% | `rich` |
| extreme | 15+ | 58 | 3% | `rich` |

**全量的动画中位数只有 1.8 条/页**（P90 是 9.8）。也就是说「大部分模板几乎不动」，
真正高频动画的只占 16%。风格表里的 `极简/文艺` = zero 档，`商务/国潮` = low 档，
`科技/沉稳深色` = mid/high 档 —— 覆盖从 0 到 18 条/页的全区间。

## 生成参数（内置在引擎里）

- **边距**：上 0.16in / 左右 0.48in / 下 0.60in（上紧下松，模板中位）
- **字号**：11 档，最大字 = 正文 5 倍；标题 40 / 正文 18 / 页脚 10 / 章节编号 108
- **装饰**：3 圆点 + 3 小色块 + 细分隔线 + 页码（约 7 个/页）
- **动效**：标题 `wipe`、正文 `ascend`（逐段）、图片 `faded-zoom`、装饰 `fade`；
  时长 500ms；1 个 click 起手，其余 `with_previous` + delay 递增（瀑布）
- **切换**：`fade 800`；morph 只用于图片推镜/轮播，不做章节转场
- **版式**：`title` / `section` / `bullets` / `metrics` / `quote` / `image` / `table`；
  `bullets` 支持 `columns: 2` 与左侧图片位

## 对标指标（`scripts/verify_benchmark.py` 实测）

同一份大纲（CodeCraft 内容，6 节）跑两次：`full` 生成章节页，`compact` 不生成。

| 指标 | 模板中位 | full（15 页） | compact（9 页） |
| --- | --- | --- | --- |
| 前景形状/页 | 15.5 | 11 | **14** |
| 装饰/页 | 7.0 | 9 | 10 |
| 内容覆盖率 | 0.714 | 0.546 | **0.715** |
| 字号档数 | 11 | 11 | 9 |
| 最大/正文 | 5.0 | 6.8 | 3.8 |
| 上边距 | 0.021 | 0.049 | 0.045 |
| 动画/页 | 15 | 10.7 | **15.8** |
| `layout_check` 溢出 | — | 0 | 0 |

**覆盖率只受章节页占比影响**：章节页只有编号与标题，天然空。
`--compact` 跳过章节页，覆盖率与动画密度立刻落到模板中位；需要章节过渡时用 `full`。

```bash
python scripts/build.py outline.json --out deck.pptx --task 路演 --compact
```

## 结构

```
pptx-skill/
├── SKILL.md
├── assets/            # 风格、配色、版式、动效、装饰素材库

└── examples/          # 大纲样例与产出
```

## 限制

- 引擎只有 9 种内置版式，**不支持 freeform 自由曲线**（模板里国潮/工科类视觉的核心）。
- 不读入 .potx 母版；如需完全复刻某个模板，应改用「复制页 + 改元素」的 morph 流程（见 pptforge）。
- 图片需自备（`points` 页可给 `image` 路径），素材库不含图片。
- 动画分级（按系列/类别）与媒体类动画在 COM 上不可用，未纳入。
